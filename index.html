FIELD GUIDE  ·  WINDOWS EDITION  ·  FOR FIRST-TIME BUILDERS

Turn a Windows PC into your own private cloud

Replace Google Photos / Drive-style backup with a server you own. Built on Docker Desktop, Nextcloud, Tailscale, and Windows' own file sharing. Every command runs in PowerShell.

BUILD TIME1–2 hours
SKILL LEVELComfortable copy-pasting
COST$0 (existing hardware)
NEEDSWindows 10/11 + 1 external drive

What you're building

Same architecture as the Linux edition, with fewer fights. Windows already owns your NTFS drive natively, so the permission problems that dominate the Linux guide mostly vanish. Docker still does the heavy lifting.

← swipe to see the full diagram →
FIG. 1 — Every device reaches the server through one private tunnel. Nothing is exposed to the open internet.

Two decisions carry the build:

  • The database lives in a Docker named volume on your internal drive. Never point Postgres at an external drive. It is slow and one unplug away from corruption.
  • The external drive is bridged in only as storage space. Nextcloud reads and writes files there. It never depends on it to run.

Before you start

what you need, and what to accept going in

  • Windows 10 (22H2) or Windows 11, with admin rights. Windows Home works.
  • Virtualization enabled in BIOS/UEFI. Check Task Manager → Performance → CPU → "Virtualization: Enabled". If it says Disabled, turn it on in BIOS first or Docker will not start.
  • At least 8 GB RAM. Docker's WSL2 backend can take several GB.
  • An external drive with a fixed drive letter (the guide uses D:). Your existing files stay untouched. No formatting.
  • Willingness to see things break once or twice. That is normal.
SET EXPECTATIONS One PC with one external drive is a testing setup, not a backup. Anything irreplaceable needs a second copy somewhere physically separate.

How to open PowerShell as Administrator

Press the Windows key, type PowerShell, right-click the result, choose Run as administrator. Approve the prompt. The title bar should say "Administrator".

01

Install the tools

WSL2, Docker Desktop, and Tailscale

Step 1: Install WSL2

Docker Desktop needs the Windows Subsystem for Linux underneath it.

PowerShell (Admin)
wsl --install

Restart when asked.

Step 2: Install Docker Desktop and Tailscale

PowerShell (Admin)
winget install -e --id Docker.DockerDesktop
winget install -e --id Tailscale.Tailscale

Restart again. Open Docker Desktop once and accept the terms. Wait until the whale icon in the tray stops animating.

Step 3: Make Docker start with Windows

Docker Desktop → Settings → General → tick Start Docker Desktop when you sign in to your computer. Skip this and your server dies after every reboot.

Step 4: Verify

PowerShell
docker --version
docker compose version
wsl --status

All three should print versions or status, not errors.

COMMON FAILURE — WSL WON'T INSTALL Error mentioning virtualization or "0x80370102" means virtualization is off in BIOS. Reboot, enter BIOS (usually F2, F10, or Del), and enable Intel VT-x or AMD SVM. Then retry.
COMMON FAILURE — "winget" NOT FOUND Older Windows 10 builds lack winget. Install App Installer from the Microsoft Store, or download Docker Desktop and Tailscale directly from their websites.
02

Stand up Nextcloud

the actual cloud storage app

Step 1: Create the project folder

PowerShell
mkdir C:\cloud
mkdir D:\CloudStorage      # change D: to your external drive letter
cd C:\cloud
notepad docker-compose.yml

Notepad asks to create the file. Click Yes.

Step 2: Paste the configuration

docker-compose.yml
services:
  db:
    image: postgres:16
    restart: unless-stopped
    volumes:
      - db_data:/var/lib/postgresql/data
    environment:
      POSTGRES_PASSWORD: choose-a-strong-password
      POSTGRES_DB: nextcloud
      POSTGRES_USER: nextcloud

  app:
    image: nextcloud:latest
    restart: unless-stopped
    ports:
      - 8080:80
    depends_on:
      - db
    volumes:
      - app_data:/var/www/html
      - D:/CloudStorage:/mnt/external_storage
    environment:
      POSTGRES_HOST: db
      POSTGRES_PASSWORD: choose-a-strong-password
      POSTGRES_DB: nextcloud
      POSTGRES_USER: nextcloud

volumes:
  db_data:
  app_data:

Change the password. Use the same one in both places. Change D:/CloudStorage to your path, with forward slashes. Save the file, and confirm Notepad did not add .txt to the name.

WHY NAMED VOLUMES db_data and app_data are managed by Docker inside its own virtual disk on C:. That is exactly what keeps Postgres happy. Only the storage folder touches the external drive.

Step 3: Launch

PowerShell
cd C:\cloud
docker compose up -d
docker compose ps

First run downloads a few hundred MB. Both services should show running. If Windows Firewall pops up, allow private networks.

Step 4: Finish setup in the browser

Open http://localhost:8080. Fill in:

  • Admin username and password: pick a strong one. This account is reachable remotely later.
  • Database: PostgreSQL
  • Database user: nextcloud
  • Database password: whatever you set in the file
  • Database name: nextcloud
  • Database host: db

Install the recommended apps if you like. Skip Talk if the PC is modest.

DEAD END WE HIT — "ACCESS DENIED" OR "COULD NOT TRANSLATE HOST NAME" Both come from the database being half-initialized or never starting. Do not patch it. Wipe and restart clean: 
docker compose down -v
docker compose up -d
The -v deletes the volumes, so the database re-initializes with the password currently in your file. Then reload the setup page.

Step 5: Bridge in the external drive

  1. Profile icon → Apps → search external storage → Enable.
  2. Profile icon → Administration settings → External storage.
  3. Add a row: name External Drive, type Local, path /mnt/external_storage. Save.
  4. Go to Files. The new folder appears. Upload a test file.
  5. Check that the file shows up in D:\CloudStorage in Explorer.
WANT YOUR OLD FILES VISIBLE TOO? Change D:/CloudStorage in the compose file to D:/, then run docker compose down and docker compose up -d. This exposes the entire drive to every account you grant access. Decide deliberately.
03

Remote access

reach your files from anywhere without opening router ports

PowerShell
tailscale up
tailscale ip -4      # note this, e.g. 100.x.x.x

tailscale up opens a browser login. Install the Tailscale app on your phone and sign in with the same account.

Fix the "untrusted domain" error before it happens

Nextcloud only answers to addresses on its allowlist. Add your Tailscale IP with one command. No file editing.

PowerShell
cd C:\cloud
docker compose exec -u www-data app php occ config:system:set trusted_domains 1 --value="100.x.x.x:8080"

Replace 100.x.x.x with your real Tailscale address.

AN HONEST LIMITATION Tailscale sometimes cannot make a direct connection and falls back to a relay (DERP in tailscale ping). Browsing and small files stay fine. Big transfers on mobile data get slow. Enabling UPnP on the router sometimes fixes it. ISPs using CGNAT may block it entirely. That is the network, not your setup.
04

Local file sharing

replaces Samba. Windows has this built in.

PowerShell (Admin)
New-SmbShare -Name "shared" -Path "D:\CloudStorage" -FullAccess $env:USERNAME
hostname                # your PC name
ipconfig                # find your IPv4 address

Connect from another device on the same wifi

DeviceHow
WindowsFile Explorer → address bar → \\PC-NAME\shared
MacFinder → ⌘K → smb://PC-IP/shared
AndroidAny SMB-capable file app → add server by IP
iPhoneFiles app → Connect to Server → smb://PC-IP/shared
MISTAKE WE ACTUALLY MADE Typing \\PC-NAME\shared into a web browser gives "refused to connect". Browsers do not speak SMB. Use File Explorer's address bar.
IF NOTHING CONNECTS Set your network profile to Private (Settings → Network & Internet → your connection → Network profile). Public profiles block file sharing. Also confirm File and Printer Sharing is allowed in Windows Defender Firewall. The share needs a Windows account with a password. Blank-password accounts are refused over the network.
05

Connect your devices

automatic photo backup. The point of the whole build.

Phone: automatic photo and video backup

  1. Install the Nextcloud app.
  2. Log in with http://100.x.x.x:8080 (your Tailscale address). Tailscale must be connected on the phone.
  3. Menu → Settings → Auto upload.
  4. Turn on photo/video upload, pick folders (Camera by default), choose wifi-only or wifi plus mobile data.
  5. Set Tailscale and Nextcloud to unrestricted battery use on the phone. Otherwise uploads silently stop in the background.

PC: optional sync client

PowerShell
winget install -e --id Nextcloud.NextcloudDesktop

Skip it on the server PC itself. It only makes sense on other computers you want kept in sync.

MINOR BUG WE HIT — IN-APP PDF PREVIEW The Android app's built-in preview can hang forever on PDFs while the file downloads fine. Workaround: ⋮ menu → Download, then open it in your normal PDF viewer.
06

Keep it running 24/7

Windows wants to sleep and reboot. Stop both.

1. No sleep, lid close does nothing

PowerShell (Admin)
powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setdcvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /setactive SCHEME_CURRENT

Verify in Control Panel → Power Options → "Choose what closing the lid does".

2. Tame Windows Update reboots

Settings → Windows Update → Advanced options → Active hours. Set the widest window allowed. Windows still reboots eventually. Because Docker starts at sign-in, enable automatic sign-in or the server stays down at the login screen until you type a password.

3. Cap Docker's memory

WSL2 grabs RAM aggressively. Create %UserProfile%\.wslconfig:

.wslconfig
[wsl2]
memory=4GB
processors=2
PowerShell
wsl --shutdown

Then restart Docker Desktop.

HEAT AND POWER Lid-closed laptops trap heat. Use a hard, elevated surface. Keep it plugged in permanently.

Drive health

Many USB enclosures hide SMART data. Try winget install -e --id CrystalDewWorld.CrystalDiskInfo. If it shows nothing, you have no early warning. Keep a real backup.

Security & maintenance checklist

  • Use a real admin password. It is the actual attack surface once remote access is on.
  • Know what you expose. Mounting D:/ instead of a subfolder shares everything on the drive.
  • Keep trusted_domains minimal. Only addresses you really use.
  • This is not a backup. One drive, one machine, no redundancy.
  • Stay plugged in. Sleep is off, so a battery just drains.
  • Update monthly: cd C:\cloud; docker compose pull; docker compose up -d. Data lives in volumes and is untouched.
  • Back up the database too. The Nextcloud index lives in the volumes on C:. Export it occasionally: 
    docker compose exec db pg_dump -U nextcloud nextcloud > D:\CloudStorage\nextcloud-db-backup.sql
  • Review access every so often, especially if you shared passwords.

Troubleshooting

symptom → real cause

SymptomReal cause
Docker Desktop won't startVirtualization off in BIOS, or WSL not installed
localhost:8080 refuses to connectDocker Desktop isn't running, or containers are stopped. Run docker compose ps
Setup: "Access denied" / "could not translate host name"Database half-initialized. docker compose down -v and retry
Container fails: drive/path not foundExternal drive unplugged or its letter changed. Fix the letter in Disk Management
"Access through untrusted domain"Address missing from trusted_domains
Can't open the SMB shareNetwork profile Public, firewall rule, or account has no password
Server dies after rebootDocker not set to start at sign-in, or PC stuck at the login screen
Works on wifi, crawls on mobile dataTailscale relaying through DERP
PC feels slow and RAM is fullWSL2 memory unbounded. Add .wslconfig
PDF preview spins forever in the appApp-side bug. Download and open externally
Whole PC's internet got slowLarge initial photo sync saturating upload. Throttle sync, or schedule it overnight
09

Full removal

tear it all down without touching your original files

PowerShell (Admin)
cd C:\cloud
docker compose down -v
docker system prune -a --volumes

Remove-SmbShare -Name "shared" -Force
tailscale down

winget uninstall -e --id Docker.DockerDesktop
winget uninstall -e --id Tailscale.Tailscale
wsl --unregister docker-desktop
wsl --unregister docker-desktop-data

cd C:\
Remove-Item -Recurse -Force C:\cloud
Remove-Item -Recurse -Force D:\CloudStorage   # only the folder this guide created

Also delete %UserProfile%\.wslconfig if you made it, and uninstall the Tailscale and Nextcloud apps from your phone. Original files on the external drive are untouched as long as you delete only the folder this guide created.
